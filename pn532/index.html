編輯與匯出

寫入會覆蓋目標卡資料，包含扇區尾塊的金鑰與存取位。一般原廠卡的 Block 0 不可改；完整寫入僅針對相容的特殊測試卡。

4-byte UID 寫入

讀取來源卡的 UID／ATQA／SAK，寫到支援改寫 Block 0 的特殊卡；不複製其他資料或金鑰。

自動模式只有在 Gen1a 後門無法開啟時，才會用這些 Key 嘗試 CUID。
普通 MIFARE Classic 卡的 UID 無法改寫。請確認目標是你有權操作的 Gen1a／CUID 特殊卡。

Key Detector（北方智能卡）

此工具需搭配「單卡嗅探王」特殊卡。PCR532 負責設定與讀取該卡；一般 M1 卡不具備記錄功能。

需另備相容的「單卡嗅探王」，並在你有權測試的讀卡環境收集紀錄；取得的 Key 只對對應卡片與區塊有意義。
